# IAM-Home-Lab
Hands on Identity and Access Management Labs using Entra ID
## Lab 1: Users and Groups
**Goal:** Create a user and a security group, and use group-based access.

**What I did:**
- Created a free Entra ID tenant
- Created multiple test users
- Created a security group (IT HELPDESK) and added the user
  
**What I learned:** Access is managed through groups, not individuals (RBAC, least privilege).
